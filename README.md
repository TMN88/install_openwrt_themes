# Установка тем LuCI для OpenWrt

Меню выбора **Footstrap**, **Argon**, **Aurora**. Поддерживаются OpenWrt **24.10 / opkg** и **25.12 / apk**. Актуальному Footstrap требуется 24.10.3 или новее.

## Запуск по SSH

```sh
wget -O /tmp/install-themes.sh https://raw.githubusercontent.com/TMN88/install_openwrt_themes/main/install.sh && sh /tmp/install-themes.sh
```

Выберите номер темы. Скрипт скачает пакет последнего стабильного релиза автора, установит зависимости через родной менеджер пакетов и активирует тему. Для APK используется `--allow-untrusted` только для скачанного пакета автора; системные настройки проверки подписей не меняются. Когда GitHub предоставляет SHA256, скрипт проверяет её. Если суммы нет, выводится уведомление; загрузка идёт по HTTPS.

Повторный запуск переключает на уже установленную тему без обновления. Скрипт не удаляет другие темы. Перед установкой сохраняется `/etc/config/luci`; при ошибке восстанавливается прежнее активное оформление. Установленные зависимости и пакеты автоматически не откатываются. В конце выводится команда возврата к прежней теме. Обновите браузер через Ctrl+F5; перезагрузка роутера не требуется.

Если установлен старый `luci-app-argon-config`, перед Argon устанавливается миграционный пакет из того же релиза по инструкции автора. Отдельное приложение настройки Aurora в этот установщик не входит.

Нужны root, установленный LuCI, доступ к GitHub и рабочие системные репозитории. При сетевой ошибке или отсутствии подходящего пакета скрипт останавливается; принудительное игнорирование зависимостей не используется. Сборки SNAPSHOT и другие ветки пока не поддерживаются.

## Источники тем

- Footstrap: https://github.com/VizzleTF/luci-theme-footstrap
- Argon: https://github.com/jerrykuku/luci-theme-argon
- Aurora: https://github.com/eamonxg/luci-theme-aurora

Темы принадлежат их авторам; этот репозиторий содержит только установщик.

## Проверка

Предусмотрена CI-проверка синтаксиса и ShellCheck. Установка на физическом роутере пока не проверена.
